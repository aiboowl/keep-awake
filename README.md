# Не засыпать ☕

Небольшое приложение для macOS: оставляет Mac работающим во время загрузок,
длительных вычислений и других фоновых задач. Окно управления и значок с чашкой
в строке меню. Интерфейс на русском языке.

**macOS 13 Ventura или новее · Apple Silicon и Intel · без сторонних зависимостей.**

## Скачать и запустить

1. Откройте [последний релиз](https://github.com/aiboowl/keep-awake/releases/latest).
2. Скачайте `KeepAwake-1.1.2-universal.zip` из раздела **Assets** и распакуйте.
3. Перенесите **Не засыпать.app** в папку «Программы» и откройте.
4. Выберите нужный режим. При первом включении полного или эко-режима macOS
   попросит пароль администратора для однократной настройки.

Готовому приложению не нужны Xcode, Python, Terminal или папка с исходниками.

### Если macOS блокирует первый запуск

Релиз подписан локальной подписью (ad hoc), без Apple Developer ID и нотариализации.
Поэтому macOS может заблокировать приложение, скачанное из интернета.
После первой попытки открытия зайдите в **Системные настройки → Конфиденциальность
и безопасность → Всё равно открыть**, затем подтвердите открытие.
Эта кнопка доступна некоторое время после попытки запуска.
[Инструкция Apple](https://support.apple.com/en-us/102445).
На управляемом рабочем Mac это действие может быть ограничено администратором.
Альтернатива — собрать приложение из исходников ниже.

## Режимы

| Кнопка | Что происходит |
| --- | --- |
| Только с открытой крышкой | Защита от сна по бездействию, без прав администратора. |
| Включить для закрытой крышки | Системный запрет сна без лимита батареи. |
| Эко: только от зарядки | Снимает собственный запрет сна при отключении питания. |
| Эко: до 20% | Снимает собственный запрет сна при заряде 20% и ниже без зарядки. |
| Выключить экран | Гасит дисплей, сохраняя текущий режим. Мышь или клавиша включит экран. |
| Вернуть обычный сон | Восстанавливает сохранённую настройку и удаляет автозапуск защиты. |

**Закрытие окна и выход из приложения не отключают защиту.** Она сохраняется
после повторного входа в macOS. Для отключения нажмите **«Вернуть обычный сон»**.

После срабатывания эко-лимита режим включается заново вручную. Подключение зарядки
само не включает его. Эко-режим разрешает сон, но не принуждает Mac уснуть:
другие приложения могут удерживать его активным. При ошибке восстановления
контроль батареи повторяет попытку раз в минуту. Не удаляйте разрешение
переключения без пароля, пока защита включена.

Работа с физически закрытой крышкой зависит от конкретного Mac и конфигурации.
Проверьте продолжение своей задачи после закрытия и открытия крышки.
Работающий ноутбук оставляйте на твёрдой поверхности с доступом воздуха.

## Собрать самостоятельно

Нужны macOS 13+ и Apple Command Line Tools. Если инструментов нет:

```sh
xcode-select --install
```

После окончания установки:

```sh
git clone https://github.com/aiboowl/keep-awake.git
cd keep-awake
bash scripts/build.sh
bash scripts/install.sh
```

Также можно скачать **Code → Download ZIP**, распаковать и дважды нажать
**Установить.command**. Скрипт соберёт универсальное приложение, установит его
в `~/Applications` и откроет. Не запускайте сборку через `sudo`.

Сборка без установки: `bash scripts/build.sh`. Результат — `build/Не засыпать.app`.
Создание распространяемого архива: `bash scripts/package.sh`.
Результат — `dist/KeepAwake-1.1.2-universal.zip` и `dist/SHA256SUMS.txt`.

## Управление из Terminal

Для готового приложения в `/Applications`:

```sh
CONTROL='/Applications/Не засыпать.app/Contents/Resources/keep_awake.sh'
bash "$CONTROL" status
bash "$CONTROL" start --idle
bash "$CONTROL" setup
bash "$CONTROL" eco --ac-only
bash "$CONTROL" eco 20
bash "$CONTROL" start
bash "$CONTROL" screen-off
bash "$CONTROL" stop
```

Если устанавливали из исходников, замените `/Applications` на `$HOME/Applications`.
В репозитории также доступен `bash scripts/keep_awake.sh status`.
Эко-режим из исходников требует установленного приложения с BatteryGuard.

## Права и системные изменения

Приложение не отправляет данные в сеть. Использует штатные `caffeinate -i`,
`pmset`, пользовательские LaunchAgents и уведомления питания IOKit.
Контроль батареи событийный; окно обновляет состояние раз в минуту только
при активном приложении.

Однократный `setup` добавляет в `/private/etc/sudoers.d/` правило для текущего
пользователя, разрешающее без пароля только две точные команды:
`/usr/bin/pmset -a disablesleep 0` и `/usr/bin/pmset -a disablesleep 1`.
Правило проверяется через `visudo`. Остальные команды администратора требуют пароль.
Режим с открытой крышкой не требует этого правила.

Для совместимости с прежней версией сохранены технические имена:

- Состояние: `~/Library/Application Support/AmsterApart/keep-awake/`.
- Автозапуск: `~/Library/LaunchAgents/local.amster-apart.keep-awake.plist`.
- Контроль батареи: `~/Library/LaunchAgents/local.amster-apart.keep-awake.battery.plist`.
- Правило: `/private/etc/sudoers.d/amster-keep-awake-<UID>`.

## Удаление

1. Сначала нажмите **«Вернуть обычный сон»** и убедитесь, что защита выключена.
2. При необходимости удалите разрешение без пароля:
   `bash '/Applications/Не засыпать.app/Contents/Resources/keep_awake.sh' remove-access`.
   Для установки из исходников используйте путь в `~/Applications`.
3. Закройте приложение через меню чашки и удалите его из «Программ».
4. После успешного отключения можно удалить каталог состояния, указанный выше.

Если исходная настройка потеряна, обычное разрешение сна можно вернуть вручную:
`sudo pmset -a disablesleep 0`. Это меняет глобальную настройку, поэтому сначала
проверьте, не нужен ли запрет другой программе.

## Проверки и ограничения

```sh
python3 -m unittest discover -s tests -v
bash scripts/build.sh
```

19 тестов проверяют управление и восстановление через подставные системные утилиты,
не меняя настройки Mac. Сборка проверяет подпись, выполняет самопроверку BatteryGuard
и читает статус через готовое приложение. Физическое достижение 20%, ночная работа
и закрытие крышки на других Mac не проверены. Расход энергии не измерен.
Сборка содержит обе архитектуры; выполнение Intel-версии на физическом Intel Mac
отдельно не подтверждено.

## Разработка и релизы

Исходники интерфейса и контроля батареи находятся в `scripts/macos-keep-awake/`,
управление системой — в `scripts/keep_awake.sh`. CI собирает универсальное приложение,
проверяет тесты и сохраняет архив. При отправке тега `v*` публикуется GitHub Release.
Версия тега должна совпадать с `CFBundleShortVersionString` в `Info.plist`.
